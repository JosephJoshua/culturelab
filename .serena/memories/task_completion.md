# Task completion checklist
- Ensure pages render without runtime errors via `npm run dev` locally.
- Run `npm run lint` (Biome) to catch formatting/lint issues; fix and reformat with `npm run format`.
- For UI tasks, spot-check main routes in browser: `/`, `/events`, `/events/[slug]`, `/blog`, `/members`, `/about`, `/account`, `/admin`, custom 404.
- Verify Tailwind styles apply and fonts load; ensure Chinese copy appears where required.
- If adding assets, confirm correct paths under `public/` and references updated.
- Summarize changes and note any TODOs or follow-ups for data persistence or integrations.
